# v2.2 — 원작 검수 대장·8+1 모델·시점별 Evaluation 1차 연구

상태: **2026-10-23 / 연구 DRAFT / 원작 직접 대조 0건 / 정식 능력치 평가 0건 / 기존 전투력과 모델 미변경**.

이번 작업에서 실제로 검증한 것은 (a) 사용자가 제공한 v2.1 데이터 계약의 구조·Record ID 및 기존 교전/발언 후보, (b) 네이버웹툰 **작품 및 일부 회차 목록**, (c) 명시된 팬 편집형 2차 자료의 주장이다. **유료 회차의 컷과 발언을 직접 읽거나 확인하지 않았다.** 출처가 공식 목록이라고 해서 해당 장면·대사를 원작 대조 완료로 승격시키지 않는다.

## 1. 실제 원작 대조를 위한 19건 질문 대장

- 데이터: `data/pilot-review-queue.v2.2.json`. Evidence **A01~A04, L01~L04, R01~R04 = 12개**, Statement **ST01~ST07 = 7개**.
- 모든 기록은 `verification=not-directly-checked`, `approval=none`이며 점수·E1/E2/E3 충분도 미판정.
- P1/P2는 **검토 순서** 표시용으로 점수, 근거 가중치 또는 작품 내 강약이 아니다.
- `chapterCandidate`는 2차 자료 출처의 후보 회차이며, 목록에 회차가 존재하는지와 **장면 내용** 확인 여부는 별개.
- 원작을 보는 최종 사용자가 기록할 최소 필드: `Record ID / 부·회차 / 컷 위치(개인 검수 메모) / 등장인물·대상·무장·거리 / 순서·시점 / 부상·피로·목적·정보 / 사실 문장 / 대안·반증 / 확인 주체·날짜`. 저작권 확인 전 이미지는 게시하지 않는다.

## 2. 8+1 능력치 중복·정의 검수 (모두 실험 가설)

| 현재 화면의 축 | 임시 관찰 단위 | 특히 분리해야 할 대상 |
|---|---|---|
| 신체 역량 | 근력·폭발력 등 기본 신체 산출 | 맷집·회복력·유효타 결과와 분리 |
| 기동 | 접근/이탈, 위치변경과 거리 확보 | 공격 개시 순간의 반응과 분리 |
| 반응 | 돌발 자극의 인지부터 실제 대응까지 | 사전 정보로 움직임을 예측한 전술·판단과 분리 |
| 방어 | 회피·흘리기·막기와 피격 억제 | 손상에 견디는 체력/부상 후 지속 기능과 분리 |
| 지속전 | 시간·피로에 따른 본인 수행 유지 | 상대 피로 유도나 일회성 맷집과 분리 |
| 전술·판단 | 주어진 정보를 이용한 전투 목표/전략 선택 | 실제 변수 발생 후 상황 대응과 분리 |
| 부동심 | 공포·분노·압박에서도 자기 판단의 안정적 유지 | 상대 심리에 개입하는 **심리전**, 감정 표현 자체와 분리 |
| 상황 대응 | 예상과 다른 조건 변화 후 전법 조정 | 원래 계획된 복잡한 기술 연쇄와 분리 |
| +1 전문 역량 | 사격·도검·단검·맨손 등 해당 인물에게 **근거로 확인된** 분야별 숙련 | 다른 종류 전문성을 모두 억지로 평균내거나, 미사용을 0점 처리하지 않기 |

특히 **공격 실효성**은 전투의 결과에 가까우므로 현재 8+1 안에서 독립 공통축으로 무작정 편입하지 않는다. 8축과 전문성이 동일 성과를 반복 설명할 때, Evidence의 `primary / secondary / context` 역할은 **가중치 배율이 아니며**, 한 결과를 두 개 축에 무조건 더하지 않는다.

제안: M0 개별 관찰 + 검토 질문 단계 유지 → 축 경계가 실제 장면에서 구분 가능한지 3인 자료로 확인 → 5점 기준과 조건부 2.5점 세분화를 별도 감도시험 → 필요 시 M1/M2 계산 시도. 지금 **점수·확정 가중치·승률 산출 없음**, 충분도 E1/E2/E3 및 원작 대조와 승인 상태 독립.

아래 판단은 **사용자가 제안한 후보**와 **팬 편집형 2차 자료**를 이용한 후속 **검수 우선순위**이며 원작 공식 설정을 직접 확인하지 않았다.

| ID | 인물 | 확인할 2차 주장 (실제 원작 미확인) | 임시 판단 |

| `char-051` | 임무열 | 과거 해결사 활동·위상을 기술하는 2차 자료 [S4] | **과거 명성만으로 정량 이원화하지 않기**; 비교 가능 전투 표본부터 확인 |

동일 Character에 Evaluation 상태를 복수로 두되 `subjectState = era/arc + 조건`을 나중에 연결한다. 기존 등록 Character와 Group ID는 그대로 유지한다. 생존·사망이나 노쇠/전성기 자체도 원작 검수 전까지 확정 상태로 옮기지 않는다.

실제 분리 결정에는 **최소한** (a) 다른 두 시점에 대한 원작/공식 확인, (b) 비교 가능한 직접 교전 또는 공식적으로 다른 상태를 구분하는 근거, (c) 상태별 부상·무장·심리·목적 보정 가능성, (d) 데이터 충분도가 필요하다. 충족하지 못하면 ‘후기 평가 미평가’가 정답일 수 있다. 기본 표시 상태와 점수 확정은 사용자 승인 후 선택.

## 4. 완료와 잔여 게이트

- **완료:** v2.1 기존 원본을 변경하지 않고 19건 질문 대장을 별도 생성, 브라우저 UI에서 검수 질문과 ID 연결. 8+1 축 중복 위험의 정의 검토, 5인 시점 분리 후보 조사.
- **미완료:** 직접 원작 대조, 전투 Phase 최종 확정, 시점 상태 분리 승인, 점수/모델 확정, 명대사 선정, 실제 독자 사용성 파일럿.
- **다음 사용자 검수:** 우선 `L04` 시점별 개입, `R04` 부상 기점, `A02/A03` 경호원·무장 전환, `ST03/04/05` 발언 원문을 대조. 1부/2부 원문 출처·장면 위치가 확보되면 해당 Record ID에서 검수 상태를 정식 갱신할 수 있다.
