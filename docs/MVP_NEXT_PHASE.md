# 캐슬 읽기 전용 MVP — 배포 이후 다음 단계

상태: 2026-10-23 · 실행 범위: 텍스트 기반 공개 MVP만 / 원작 데이터·점수 미확정

## 완료 및 보존 대상

- 원본 `data/roster.v0.1.json` 109명·17조직은 수정하지 않는다.
- `index.html`은 3인 파일럿(아킬라 `char-033`, 리천 `char-087`, 류지학 `char-071`)에 초점을 맞춘 공통 UI이며, 109명 탐색이 가능하다.
- 네 영역(도감/전투력/근거/검수)을 제공한다. 자료 미연결을 작품 근거 부족이나 실력 부족으로 오해하지 않는다.
- 공개 UI의 M0 개별표시만 사용한다. M1/M2 계산·모든 수치·승패·랭킹은 비활성이다.
- 현재의 '근거 0건'은 이 버전에 연결된 데이터가 없다는 의미다. 이전 v2.1 연구 파일의 존재 여부를 부정하지 않는다.
- 사진은 아직 0장이다. 이미지를 임의 다운로드하거나 업로드하지 않는다.

## 다음 개발 게이트

1. v2.1 계약 원본(`CASTLE_DATA_CONTRACT_READINESS_v2.1_DRAFT.md` 및 로컬 계약 번들)을 수급한다. 현재 GitHub `main`에는 없다. 원본이 확보되지 않았다면 필드명·관계를 추정하여 고정하지 않는다.
2. 세 대상자의 Battle/Phase, Evidence, Statement, DecisionCase/Outcome의 ID 및 연결 관계를 실제 스키마 기준으로 검사한다. 예시 숫자·장면·대사·회차를 만들지 않는다.
3. 읽기 전용 어댑터에 출처 유형, 원작 확인 상태, E1/E2/E3 충분도, 평가 승인 상태를 별개로 표시한다. 발언 확인과 발언 내용의 진위는 별개로 둔다.
4. 도감과 근거 탭에서 같은 Record ID를 역추적하고 필터·시점·참조 무결성을 점검한다.
5. 이미지 도입은 사용자 제공 이미지를 Character ID로 연결하고, 출처·회차·권리 상태를 이미지마다 기록한 뒤 공개 가능 여부를 검토한다.

## 확인 기준

- 109명과 기존 ID 보존, 조직별 집계 일치, 미평가 인물·미사용/자료부족/적용불가의 구분.
- 3인 근거 접근과 원작 미검수 배지, 반증 누락·사건 참조 오류가 없음.
- 공개 페이지의 핵심 UI가 데스크톱 및 모바일에서 실제 작동하고, 페이지 배포 성공 상태 및 URL의 실제 응답을 별도로 확인.
- Pages 설정이 활성화되지 않았다면 GitHub Settings → Pages → Build and deployment → Source: GitHub Actions에서 1회 활성화해야 함.
