**자료 구분:** W1~W5는 팬/위키 기반 2차 자료로, 탐색 질문을 찾는 데만 사용한다. 원작 직접 검증, 공식 설정 확인, 점수 산정의 근거가 아니다. 정확한 작품 부·화·컷·원문은 아직 미확보.

## 2. 이원화 결정 조건

1. `Character`는 **한 명만 유지**한다. 동일인물을 `char-NNN-prime`처럼 추가 등록하지 않는다.
2. 과거와 후기가 **원작·공식 자료상 구분되는 시점 또는 상태인지** 확인한다. '노쇠'라는 형용사 한 번이나 단순 인기도만으로 두 점수를 강제하지 않는다.
3. 차이가 확인되면 `Evaluation.subjectState`에 시점과 주요 상태를 별도로 기록하고, 정확한 `Battle/Phase/Evidence` 참조를 연결한다.
4. 옛날 전투의 유리한 체력과 후기의 숙련·정보를 **동시에 성립하는 초상태로 합성하지 않는다**.
5. 자료가 적은 시대는 `미평가`로 두며 E3라는 이유로 점수 감산을 적용하지 않는다.
6. '기본 표시 시점', 비교 UI, 수치와 중요 평가 기준은 **사용자 승인 후** 결정한다. 기본 점수·랭킹·매치업은 현재 없음.

## 3. 대표 명대사 계약 — Statement와 분리

원피스 분석기의 `src/data/quotes/characterQuotes.ts`와 `CharacterQuote.tsx`를 **읽기 전용 참고**로 확인했다.

- 대표 명대사: 문학적·서사적 의미를 지닌 대사, 사진 아래 도감/상세의 보조적 인용 영역. 전투력 점수에 자동 영향 없음.
- Statement: 특정 인물/세력/전술 등에 관해 등장인물이 내린 **주장**의 사실, 내용의 진실성, 발언 목적, 반증과 사건 결과를 분리하는 Evidence 대상.
- 대사로 발언한 것이 확인되더라도 **그 명제가 참이라는 의미는 아니다**.
- 후속 후보 필드: `id`, `characterId`, `exactText`, `speakerId`, `workPart`, `episode`, `sceneContext`, `sourceReference`, `verificationStatus`, `publicationStatus`, `rightsReview`.
- **원작 대사 미확인·선정 전에는 내용을 생성하거나 출력하지 않는다.** 현재 레지스트리는 빈 목록이다. UI 역시 `canon-direct + approved + cleared` 상태 외에는 대표 명대사를 표시하지 않는다.
- 출처 유형, 정확한 한국어 원문, 부·화수, 발언자, 번역/인용 여부와 공개 적절성을 분리 기록한다. 비영리 프로젝트 고지로 복제 권리가 생기지 않는다.
