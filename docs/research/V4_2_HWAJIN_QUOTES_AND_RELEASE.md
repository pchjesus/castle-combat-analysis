# 《캐슬》 화진 명대사 선정 및 48인 도감 증분

사용자가 화진 인물 7명 대사를 선정하고, 기존 리천 1명의 대표 명대사는 그대로 유지하라고 요청했다. 이 변경은 `main`의 **명대사 데이터와 관련 회귀검사만** 변경한다.

## 반영
- 유우성(`char-080`, `CQ-046`) : 나무위키 인물 문서 **명대사 2부**의 '감당할 수 없을 만큼 큰 파도… 이게 유우성의 방식이다, 김신.' 전체 문구. 사용자의 구어체 요약을 그대로 옮기지 않고 출처에 표기된 2차 정리본을 저장. **원작 직접 대조는 미완료.**
- 링링(`char-081`, `CQ-047`) : '저주한다, 김신.' 나무위키 명대사 및 인물 최후 설명에서 간접 확인, 직접 컷 검수 대기.
- 도우첸(`char-082`, `CQ-048`) : '나 같은 거지 하나 없이도.. 너라면 충분히 해낼 거다. 멈추지 마라.'
- 앤디청(`char-083`, `CQ-049`) : '오늘 너의 쇼는 우리의 호기심을 자극하기에 충분했다.' (이전 제안에 대한 사용자 승인)
- 주천명(`char-084`, `CQ-050`) : '따라와라, 백의. 대륙의 수준이 얼마나 높은지 알려주마.'
- 은보(`char-085`, `CQ-051`) : '얍실한 놈.. 그 와중에도 피를 빠는구나.'
- 양사(`char-086`, `CQ-052`) : '잘 지냈냐, 말총 대가리.' (이전 제안에 대한 사용자 승인)
- 리천(`char-087`, `CQ-004`) : 기존 '네가 나무라면, 난 태산(泰山)이다.' **무변경**.

## 증분 검증
- 기존 인물 명대사 **41건**을 문자열 그대로 보존하여 총 **48명**.
- 초기 화진 로스터 8/8 명대사 확보. 기존 이스크라 19/19, 백의 10명, 아킬라 1순위, 호칭·코드네임 뜻 27명, Evidence 및 전투 모델 무변경.
- 사용자의 대사 선택과 자료의 출처 유형·원작 검수 완료 여부는 별도 기록. 2차 편집형 출처나 사용자 제공 문구는 Canon Fact / 능력치 근거로 자동 승격하지 않음.
- 기존 프로필 카드 내 대표 명대사, 접이식 추가 대사 기능, 모바일 반응형, 호칭 UI 유지.
- 정적 48건 검사, PC/모바일 7명 렌더링 확인, 실제 HTTPS 데이터 48건·화진 8명 회귀검사를 GitHub Actions로 수행.
