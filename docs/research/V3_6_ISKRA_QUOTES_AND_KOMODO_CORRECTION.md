# 《캐슬》 v3.6 — 이스크라 명대사 6건 사용자 선정 및 코모도 표기 수정

기준 2026-10-25. 기반 `feature/v3.5-user-quotes-iskra-research` @ `9a347235eecf40f6559e8984836c7ad58d77e248`.
**범위:** 별도 기능 브랜치에서 *사용자가 입력한 문장* 6건을 원문 그대로 명대사 데이터에 추가, 도감의 명대사 건수 조건 확장, `char-040`의 표기 오류만 수정. 기존 `main`이나 GitHub Pages 배포를 변경하지 않는다.

## 1. 사용자 직접 선정 6건

| 사용자 선정 문구 ID | 캐릭터 ID | 인물 | 서사적 의미 |
|---|---|---|---|

| `CQ-022` | `char-027` | 크로트 | 강자들을 수없이 겪고도 살아남은 베테랑 |

원문은 [22인 명대사 데이터](../../data/character-quotes.v3.4.DRAFT.json)에 **사용자 채팅 문구 그대로** 보존한다. 기존 16건을 그대로 유지하며, 아킬라 `CQ-012`의 *사용자 대표 1순위* 표시도 유지한다.

모두 **user-nominated**이며, 이 턴에 원작 컷의 회차/대사 직접 대조는 수행하지 않았다. 별도 출처 페이지를 확인하지 않은 이번 6건을 기존 9건과 동일하게 자동으로 '나무위키 원문 검수 완료'라 부르지 않는다. 사용자 제공 전사, 원작 추가 검수 대기라고 표시한다. 도감에서 22건의 원문을 표시하지만 공식 작품·원작 직접 검수 및 인용 권리 승인을 뜻하지 않는다.

## 2. `코도모` → `코모도` 정정

사용자의 **명시적 원작 표기 정정**에 따라 기존 `char-040`은 인물 ID, 초기 이스크라 소속, 순서, 다른 필드를 그대로 유지한 채 `name` 값만 **코모도**로 수정.

- `data/roster.v0.1.json`: ID `char-040`만 수정
- `index.html`: `roster-payload` 내 동일 인물명만 동기화
- 이전 [v3.5 이스크라 연구](../../data/research/iskra-quotation-candidates.v3.5.DRAFT.json)에 남겨둔 '코도모/코모도 불확실성'은 **정정 전 역사적 연구 기록**으로 보존
- v3.6 [이스크라 최신 선정 상태](../../data/research/iskra-quote-selection-status.v3.6.DRAFT.json)에 정정 주체·수정 항목·현재 명칭을 기록

이 변경은 새 Character ID를 만들지 않고, 기존 Evidence·Statement·전투 계산 모델을 수정하지 않는다.

## 3. 이스크라 선정 현황

**초기 이스크라 로스터 19명**을 기준으로 현재 대표 대사를 확보한 인물은 총 **10명**: 메드베디, 크리사, 크로트, 라텔, 그롤라, 아킬라, 샤모, 프리깃, 구스타프, 블랙맘바.

다음 검수 대상 **9명**: 샤이어, 판테라, 바이슨, 콘, 헤론, 오울, 스내퍼, 코모도, 잭슨.

이는 현재 로스터의 `initialOrganizationId === "iskra"` 분류에 한정한다. 과거 김신·서진태 이스크라 활동 이력이나 구/신 계파 전체를 배제하는 기준이 아니다. 미선정 인물에게 잘못된 대사나 임의 회차를 만들어 넣지 않는다.

## 4. 구현과 검증 범위

- `index.html`의 미리보기 입력 유효성 판별 조건을 **16건→22건**으로 수정. 인물 ID 기반 기존 렌더링, HTML 이스케이프, 원작 검수 대기 표시는 유지.
- `data/character-quotes.v3.4.DRAFT.json` 파일명·스키마 버전을 유지하는 **호환성 우선 확장**. 장기적으로 파일명과 스키마 버전 정비는 별도 모델 변경 검토 대상.
- 변경에 따라 기존 명대사 정적검사 v3.4/v3.5의 예상 건수를 갱신하고, v3.6 신규 정적검사에서 정확한 여섯 문장, 고유 22인, 로스터와 HTML 데이터 완전 동일성, 이스크라 10/19, 원작 검수/전투 점수 승격 0을 점검.
- **실제 GitHub Actions 성공 여부는 실행 후 별도 보고**. Playwright 등 PC·모바일 브라우저 직접 사용검증, Pages 배포, 원작 직접 검수는 해당 작업을 수행하지 않는 한 완료라고 말하지 않는다.
