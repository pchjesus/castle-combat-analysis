# 《캐슬》 v3.1 — 관찰 기준·축 충돌 판별 및 원작 검수 준비 (승인 전 DRAFT)

기준: 2026-10-25. 바탕 `research/v3.0-l2-axis-fairness-pilot` 커밋 `9bcd29cf2178c29d408289e54f737ef3c2f3099c`; 확인 당시 `main` `4766cad4ea61be7727ee0949e4c65bc228dc36c9`. 본 변경은 **연구 데이터, 정적 검증, 이 문서만** 다룬다. **웹앱·로스터·기존 Evidence/Statement·점수 엔진·배포를 변경하지 않는다.**

## 1. 연구 질문과 현재 판정

**질문:** 아킬라·리천·류지학에게 적용한 8개 공통축 + 전문 분야 보존 규칙이 (a) 직접 관찰 가능한가, (b) 다른 축과 구분 가능한가, (c) 분석자마다 일관적인가, (d) 자료량의 차이를 점수·완료도 차이로 바꾸지 않는가?

**판정:** 기존 12개의 Evidence 후보에 **표준 검수 양식과 8개 축의 관찰 기준을 부여하는 구조적 시험은 수행**. 그러나 **원작 컷 직접 대조 0건**, 독립 검토자 분류 0건이므로 **경험적 구분타당성·평정자 간 일치도는 아직 미검증**. 모델의 능력치 스케일, 축 가중치, E등급, 승률·순위, 정식 평가 변경 **없음**.

연결된 연구 산출물:
- [v3.1 8축 관찰·판별 기준](../../data/research/axis-observation-rubric.v3.1.DRAFT.json)
- [v3.1 3인 12개 Evidence의 원작 검수용 빈 양식](../../data/research/pilot-scene-review.v3.1.DRAFT.json)

**현재 검수 양식의 `null`은 원작에 해당 사실이 없다는 뜻이 아니라 아직 기록/대조하지 않았다는 뜻.** `미사용≠자료부족≠적용불가≠능력부족`. 과거 2차 자료가 원작을 직접 확인한 근거로 승격되지 않는다.

## 2. 공통 8축 — 관찰 단위와 대표적 제외 규칙

| 축 (잠정) | 긍정적 관찰에 필요한 정보 | 단독으로는 인정하지 않는 서술 |
|---|---|---|
| **신체 역량** | 힘·폭발력의 행위와 물리적 결과를 무기/상대 조건에서 분리 | 제압·명중·승리 결과만으로 강한 완력 |
| **기동** | 시작/종료 위치, 접근/이격, 실제 거리 변화 | 결과로 추정한 이동속도·패널 간 가상 시간 |
| **반응** | 돌발 위협→인지→행동의 시계열, 사전 예측 구분 | 이미 예측한 공격의 준비 동작을 순수 반사신경으로 간주 |
| **방어** | 위협과 막기/회피/흘리기 행동 및 결과 | 부상 사실만으로 방어 감점 |
| **지속전** | 시간·피로/손상 경과에 따른 **자기 수행**의 변화 | 상대 호흡 악화=자신의 지구력 |
| **전술·판단** | 당시 정보·목적·제약에 기반한 선택의 근거 | 잘된 결과가 곧 계획적 우수성 |
| **부동심** | 압박을 받은 뒤에도 자기 판단·행동을 유지/회복한 관찰 | 침착한 표정만으로 만점, 상대의 흔들림을 자기 부동심으로 간주 |
| **상황 대응** | 예상 밖 변화 전후의 실제 작전/행동 수정 | 계획된 재장전·다단계 전법을 자동 적응으로 계산 |

각 축은 `construct / observable / doNotUse / contrast / minimumIndependentObservation / holdWhen`으로 정의했다. **장면 하나에 여러 축이 관찰될 수는 있지만, 축마다 별도 행동·시차·조건에 관한 직접 관찰을 특정해야 한다.** 같은 한 번의 피격/명중/승리 결과를 세 축에서 세 번 보상하지 않는다.

전문 역량은 `사격/도검/단검/맨손/근접` **후보 도메인을 복수로 보존**하며 대표 전문 +1 선정, 도메인 평균, 불참 도메인 0점 대입을 모두 보류했다. 근접·맨손 후보는 향후 정의 중복 여부를 확인할 필요가 있다. 심리전·공격 실효성·상대 피로·부상 상태는 현재 **비채점 해석·조건 렌즈**다. 기존 8축에 새 점수 축을 추가한 것이 아니다.

## 3. v3.0 자료에 연동한 5개 축 충돌 판별 과제

| 기존 ID | 우선 검증할 축 경계 | 판별에 필요한 원작 사실 | 미확인 시 |
|---|---|---|---|
| **A03 (아킬라)** | 전술·판단 / 상황 대응 / 사격·기동 | 기존 무장 전환 계획과 돌발 변수·재이격의 실제 선후 | 예정된 기술 루틴을 적응 성과로 가산 금지 |
| **L03 (리천)** | 전술·판단 / 심리전 렌즈 / 상황 대응 / 맨손 | 탄창 상태→기만 의도→상대 인지/선택→관절 공격의 구분 | 의도만으로 심리전 성공 확정 금지 |
| **R02 (류지학)** | 전술·판단 / 반응 / 상황 대응 | 상대 공격을 유도한 사전 행동·정보가 있었는가 | 예측과 순간 반응 사이 판정 보류 |
| **R03 (류지학)** | 도검 기술 / 반응 / 공격 결과 | 도검 기술의 조작·정확성과 실제 성과를 따로 관찰 | 결정타 하나의 복수 채점 금지 |
| **R04 (류지학)** | 방어 / 지속전 / 일시 부상 | 왼쪽 상지 부상 **기점**, 부상 전후 본인 수행의 변화 | 부상=방어 감점/지속전 가산 금지 |

이 5개는 **축을 구분하기 어려운 사건**을 의도적으로 고른 것이지 원작에서 기술이 발휘됐다는 증거가 아니다. 다른 높은 원작 검수 우선순위 **A02 (제3자 사선/시간순)**, **L04 (표영·라텔·크리사 개입의 동시성)**도 12개 양식에 함께 보존. 판별 테스트 5건과 원작 검수 우선순위 전체를 혼동하지 않는다.

**아킬라 원작 열람 진술:** v2.8/v3.0의 (i) 구스타프에 대한 심리적 우위 약화 의도, (ii) 별도 `AK-KHO`에서 `0발`/`사거리 미달`/`8/10발` 관찰은 **사용자의 원작 열람 진술**로 유지. AI가 해당 컷을 직접 대조하지 않았고, 수치-상대 매핑/기술 성과 및 원작 시계열을 확정하지 않는다. `AK-KHO`를 `pilot-A`의 A01~A04 중 하나로 합치지 않는다. ST03/ST04 등 Statement도 원문/화자/시점/진실성 독립 검증 전까지 전투 기술의 직접 근거로 승격하지 않는다.

## 4. 3인에 똑같이 적용하는 원작 검수 양식

각 Evidence 후보에는 같은 키와 같은 초기 상태를 부여한다.

1. **신원/참조:** `characterId`, `battleCandidateId`, `evidenceId`, `reviewRecordId`, 기존 `sourceIds`. 기존 로스터 이름·소속을 재저장하지 않는다.
2. **출처·검증:** 2차 의역 여부, 사용자 직접 관찰 기록 여부, AI 원문/컷 직접 확인 여부와 검수 주체/날짜/부·회차/개인용 컷 위치. **사용자 열람 진술과 AI의 원문 확인 여부는 별개**.
3. **전투 조건:** 목적, 사거리/위치, 엄폐, 무장, 탄약, 제3자, 압박, 사전 정보, 부상·피로, 참가자의 참여 순서. 현재 확인되지 않은 값은 모두 `null`.
4. **최소 관찰 단위:** 행동/상대 인지/상대 선택 변화/결과를 하나의 사건 내에서도 구분. 미확인 원작 행동 또는 Phase를 만들어 기록하지 않는다.
5. **평가 귀속:** v3.0의 `primaryCandidate`, `conditionalSecondary`, 비채점 렌즈는 **가설로만 복사**. 각 검토자가 이후 독립된 원작 관찰 단위를 근거로 분류하고 대안을 기록.
6. **모델·승인:** 8축 점수는 모두 `null`, 전문 상태 `unassessed`, 충분도 `unassessed`, 계산 비활성, 시점 분리 미결정, 승인 없음.

## 5. 독립 검토자·일관성 시험의 설계 (미실시)

**두 검토자의 독립 판단은 원작 장면의 확인 후에만** 시작한다. 검토자는 다음을 분리해서 기입한다: `(a) 실제 확인된 행동 (b) 해당 축을 선택한 이유 (c) 경쟁하는 축을 보류한 이유 (d) 같은 결과를 중복 가산하지 않은 근거`.

- *관찰 단위 수준*에서 두 검토자가 독립 분류 → 차이 기록 → 같은 근거 검토 → 사용자 승인/보류.
- 서로 다른 결론을 평균하여 하나의 점수나 등급으로 만들지 않음.
- 충분한 직접 검수 표본이 쌓이기 전 **일치율·카파 등 계수의 유의미한 수치 산출을 보류**하고 `null` 유지.
- **시점 차이와 조건 차이** 때문에 원작 자체가 같은 축을 판정할 수 없으면, 불일치를 해소하려고 단일 점수 강제 금지.

원작·공식 정보·2차 요약·국내 커뮤니티 의견은 **출처 유형**이고, 직접 대조 여부는 **검증 상태**이므로 각자 독립 기록. 국내 원작 언어 기반 자료를 우선 참고하되 2차 자료의 재인용 수는 독립된 원작 검증 수가 아니다.

## 6. 109명 확대 판단과 통과 조건

**현재 판단: 스키마 재사용 시험 가능 / 실증적으로 공정한 8+1 점수 평가 모델 판정 불가.**

확대 승인 전 최소 조건:
- 세 인물의 핵심 구분 장면에서 원작 행동·조건이 실제로 확인되거나 미확인으로 명시되어야 한다.
- 각 축의 **판별 가능 / 정보 부족 / 서로 혼재** 사례를 구분하고, 불일치한 분류는 그대로 기록한다.
- 직접 원작 검증과 독립 분류가 확인된 표본에서 축 판정 일관성을 비교할 수 있어야 한다.
- 복수 전문 분야 및 교전 정보가 드문 인물에도 `null`/미평가가 **불이익**으로 변환되지 않는지 시험한다.
- 다음 대조 표본은 방어·지속전 관찰, 복수 전문, 교전 부족, 부상/시점 분리 **조건을 충족하는 후보**로 선정하되 실제 인물 이름/점수는 이번에 임의 지정하지 않는다.
- 축 합치기·신설, 점수 스케일, 가중치, 모델 활성화, E1/E2/E3 판정은 **사용자 승인 이후**의 별도 변경.

## 7. 변경·검증·남은 한계

신규 연구용 파일 4개 + 브랜치 전용 테스트 workflow 1개를 목표로 한다. 실제 파일 및 CI 결과는 커밋·실행 후 별도 확인해 보고한다.

기존 UI, 메인 로스터 109명·조직 17개, Evidence 12개/Statement 7개 및 전체 검수 대장 19개와 ID는 **수정하지 않음**. 기존 v2.9/v3.0 정적 검사와 MVP/파일럿 정적 회귀검사를 유지한다. 이번에는 브라우저 실행 및 유료 원작 직접 검수를 수행하지 않으며 그 부분은 미검증으로 기록한다. **실제 원작 검수 완료·점수·승률·배포 완료를 주장하지 않는다.**
