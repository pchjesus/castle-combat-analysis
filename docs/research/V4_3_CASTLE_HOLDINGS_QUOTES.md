# 《캐슬》 캐슬 홀딩스 7인 대표 명대사 — 선정·변경 기록

날짜: 2026-11-01. 사용자 승인에 따라 `pchjesus/castle-combat-analysis`의 `main`에 명대사 데이터만 증분 변경한다.

## 선정 결과
- 최민욱 `char-056` / `CQ-011`: **“나의 성에도 겨울이 오겠습니까”**. 기존 `CQ-011`의 대표 대사 텍스트를 **교체**하고, 기존 문구는 데이터 파일의 `choiMinukQuoteRevision.previousExactText`에 변경 추적용으로만 보존. 기존 대사를 별도 명대사로 추가하지 않음. 2024-08-26의 팬 게시물에서 **1부 107화**로 2차 표기된 부분이며 원작 컷·구두점 직접 대조는 미실시.
- 마학영 `char-057`: 기존 `CQ-014` 대표 문구 그대로 유지.
- 마준영 `char-058` / `CQ-053`: “형의 방식으로.\n우리 형제의 가치를 보여드리겠습니다, 회장님.” (두 줄로 저장)
- 이정화 `char-059` / `CQ-054`: “공무원 새끼들이 X발 고함은.. 대장님 일 보시는데 방해되게.”
- 정단 `char-060` / `CQ-055`: “현 시간부로. 내 뒤로 선 자는 캐슬 경호대가 아니다.”
- 사인진 `char-061` / `CQ-056`: “태훈아, 이 동생은 참 실망했다. 짜치는 줄은 알았지만 자기 여자 시체를 놔두고 그길로 줄행랑을 칠 줄이야. 니가 그러고도 사람 새끼냐?”
- 마크 `char-062` / `CQ-057`: “밥값 못하면 폐기처분이 순리라서.” (직전 조사 후보에 대한 사용자 승인)

제공된 인라인 하이퍼링크 및 Markdown 굵은 서식은 대사 텍스트에 포함하지 않음. 웹툰 원작 직접 대조는 완료되지 않았으며, 부·회차 및 화자의 정확한 발언 표기는 최종 사용자 원작 검수 필요.

## 영향과 안전성
- 총 48인 → **53인 명대사**, 캐슬 홀딩스 최초 7인 **전원 선정**.
- 마학영 포함 이전 48인 등록 문구 중 최민욱을 제외한 47개 원문 완전 보존.
- 기존 명대사 카드와 접이식, 이명·코드네임 27인 프로필, 109인·17조직, 사용자 선정 아킬라 우선, 이스크라 19/19, 화진 8/8, Evidence 및 전투력 미평가 상태 무변경.
- `user-transcribed-secondary`, `branch-preview-requested` 등 기존 UI 호환 레이블을 유지하되, 실제 원작 직접 검수 0건과 전투 점수 무반영 상태를 명시. 현재 공개가 원작 공식성·인용 허락을 뜻하지 않음.

## 검증
정적 `scripts/check-public-quotes-v3.6.mjs` 및 PC·모바일 `scripts/check-iskra-quotes-browser-v3.6.mjs`에서 홀딩스 7명과 기존 48건 계약을 확인. Pages 배포 후 `scripts/check-live-pages.mjs`로 HTTPS 공개 JSON의 53건과 홀딩스 7명 원문·기존 UI를 확인.
