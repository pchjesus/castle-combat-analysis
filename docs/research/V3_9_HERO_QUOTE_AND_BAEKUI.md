# 《캐슬》 v3.9 — 상단 프로필 카드 명대사 및 백의 5명 등록

2026-10-25. 사용자 요청에 따라 운영 `main`에 직접 배포하는 범위만 변경.

## 요구사항 및 결과
- 기존 인물 도감 최하단 명대사를 제거하고, 모든 상세 탭에서 재사용하는 **상단 캐릭터 카드**의 상태 배지 아래/액션 버튼 위로 이동. 긴 대사(아킬라 포함) 전체가 보이며 모바일에서는 장식 원형 마크를 숨겨 가독성을 확보.
- 기존 31명 명대사 원문, 초기 이스크라 19/19인, 아킬라 대표 1순위 모두 보존.
- 사용자 제출 백의 5명 대표 대사 등록: 김대건(`char-006`, `CQ-036`), 표영(`char-003`, `CQ-037`), 한태철(`char-005`, `CQ-038`), 여민수(`char-007`, `CQ-039`), 구일화(`char-009`, `CQ-040`). 원문·구두점 그대로 저장.
- 같은 인물에 여러 명대사가 생길 경우, **대표 1개는 상시 표시**하고 그 밖의 인용문은 `<details><summary>다른 명대사 N개 보기</summary>`로 표시. 대표 우선순위는 `representativePriority: first/primary`, 없으면 첫 번째 적격 대사. 아직 각 인물이 하나씩만 등록되어 기본 접기 버튼은 보이지 않는다.
- JSON 파일과 기존 버전명 유지하여 기존 연결을 보존. `quotes.length` 값 최소 36, 선언된 건수와 실제 건수 동일, 고유 quote ID 검증으로 **같은 Character ID로 복수 대사 등록** 허용.
- quote 출력은 기존 `h()` HTML 이스케이프로 안전하게 렌더링, 원작 대조 대기·사용자 선정 상태와 전투 점수 독립성 유지.
- 기존 사진/유료 웹툰 컷 새로 게시하지 않음. 109명/17조직, Evidence, Statements, 전투 점수·계산, 시점별 평가 변경 없음.

## 검증
- 기존 `scripts/check-mvp.mjs`, `scripts/check-pilot-v2.1.mjs`, `scripts/check-character-images.mjs`
- 수정 `scripts/check-public-quotes-v3.6.mjs`: 36건/5명 대사 원문/이스크라 유지/로더 다중 구조/상단 렌더링/자바스크립트 구문
- 수정 `scripts/check-iskra-quotes-browser-v3.6.mjs`: PC·모바일 19명 이스크라 + 5명 백의 카드 위치, 미검증 라벨, 원문 표기, **테스트 전용 추가 인용문으로 접기/펼치기 토글**
- 기존 반응형 6개 뷰포트 회귀 검사(`scripts/check-browser-v2.1.mjs`) 유지, 실제 `scripts/check-live-pages.mjs`에서 36개 공개 JSON 로드와 hero 문자열 검사.

**검증 완료 여부는 해당 변경의 실제 Actions 실행 결과에 따르며, Push/CI/배포/원작검수는 개별적으로 보고한다.**

## 제한 사항
5명의 대사는 사용자 직접 제공 문구이되 원작 유료 컷과 직접 대조하지 않았다. 공개 인용문이 법적 허락을 자동으로 의미하지 않으며 이미지 외 텍스트도 적절한 인용 검토 대상이다.
