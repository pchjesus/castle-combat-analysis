# 《캐슬》 v2.9 — 109명 규모 확장을 위한 3단계 근거 분석 규약 (승인 전 DRAFT)

기준: 2026-10-24 · `main` `4766cad4ea61be7727ee0949e4c65bc228dc36c9`. 적용 범위는 **연구 설계·검수 준비**다. 웹앱 화면·기존 전투 데이터·점수 모델·배포는 변경하지 않는다.

## 1. 핵심 판단: 인물에게 같은 깊이의 글을 강요하지 않는다

**모든 인물에게 같은 비교 원칙을 적용**해야 하지만, **동일한 분량의 근거와 심층 가설**을 요구할 필요는 없다. 분석 깊이(L1~L3)는 캐릭터 전투력·평가 충분도 E1/E2/E3·완료 상태를 나타내지 않는다.

| 단계 | 최소 목적 | 데이터 상태와 승격 조건 | 절대 뜻하지 않는 것 |
|---|---|---|---|
| **L1 초기 프로필 틀** | 기존 109명 Character와 초깃값 분류를 추적; 전문 무장·거리·장단점은 미검증이면 빈칸 | **현재 전체 109명은 `roster-indexed-no-combat-profile`**. 신원·초기 조직조차 원작 검수 전 후보 | 109명 전부의 전투 프로필 작성·원작 확인 완료 |
| **L2 표준 전투 검수** | 대표 교전에서 사실 후보/전투 조건/해석·반론/전문 수행을 분리하여 Evidence와 연결 | **3인(아킬라·리천·류지학)은 `candidate-evidence-linked`**. 각각 기존 4 Evidence 후보 연결 및 검수 대장 4건 연결 | 원작 검증 완료, 8+1 점수 입력, E1 충분도 확정 |
| **L3 선택 심층 검수** | 심리적 의도 vs 성과, 참여자 시간순서, 시점별 격차처럼 해석이 갈리는 사건을 심층 검증 | 아킬라 심리전·원거리 계산만 **`unapproved-hypotheses-exist`**, 나머지 인물도 사건 복잡성에 따라 필요할 때만 심화 | 강함의 순위, 팬 인기도, 전투력 가산 배율 |

[109명별 적용 상태·표준 기록 틀·3인 비교 팩](../../data/research/analysis-depth-coverage.v2.9.DRAFT.json)을 **기존 로스터 Character ID 기준으로 생성**했다. 이름·초기 조직을 이 파일에 중복 저장하지 않아 둘 사이에 서로 다른 공식 설정이 생기지 않게 했다.

> **현실적인 진척 해석:** 109명에게 **L1 기록 틀만** 생성. 아직 109명 무장/거리/전법을 조사해 채운 것은 아니다. 3인에게 **L2 검수 준비 팩**을 만들었지만 원작 컷이 유료라 직접 확인·점수 승인된 인물은 0명이다. 아킬라는 L3 **연구 가설만** 축적된 상태이지 심층 평가 확정 완료가 아니다.

## 2. 한 인물에 반복 사용할 최소 표준 기록

구조는 `Canon Fact 후보 → Combat Context → Interpretation → Evaluation → Calculation`에 **출처·확인 상태**를 끼워 넣는다. 원본 Evidence를 복제하지 않고 기존 Record ID를 참조한다.

| 입력 필드 | 반드시 구분할 값 | 예시 |
|---|---|---|
| Identity | `characterId`; 소속은 로스터 **초기 분류** 링크로만 | 아킬라 `char-033` |
| Source / verification | 원작/공식/국내 분석/커뮤니티, **직접 확인 주체**, 부·회·컷, 작성일/접근 범위 | 사용자 직접 열람 진술 vs AI의 원작 미열람 |
| Canon Fact candidate | 관찰된 움직임·명중·발언의 **원문 검수 여부** | `A02` 제3자 조준 순서 **미검수** |
| Combat Context | 목적(사살·제압·호위·탈출·지연), 참가자·거리·무장·탄약·엄폐·부상·제3자·정보 | 아킬라/구스타프 제3자 개입 상황 후보 |
| Interpretation + counter | 가능한 원인과 **상충 가설/반례**를 나란히 | 근접 진입 = 상대 심리 흔들기 vs 거리 상실 손실 |
| Evaluation | 8축/전문기술 후보, `미사용/자료부족/적용불가`, 점수/근거 충분도 **독립** | 점수 `null`, 충분도 `unassessed` |
| Calculation / temporal | 현재 승인 모델인지, 특정 시점 평가 여부와 **일시 부상 조건** 구분 | 모델 비활성, 시점 분리 `not-decided` |

**설계 규칙:** `primary / secondary / context`는 Evidence 역할이지 더하거나 곱할 수 있는 수치가 아니다. 전투 목적·심리 의도·타격 결과 중 **독립적으로 확인된 행동**만 각각 능력치에 연결하고, 동일 공격의 결과를 여러 축에서 반복 보상하지 않는다.

### 전문기술 공란의 의미

`not-used`(전투에서 사용 안 함), `ability-unknown`(할 수 있는지 정보 없음), `not-applicable`(해당 전투에 적용 불가), `unassessed`(검토 전), `used-with-observation`(실제 사용 후보)를 따로 관리한다. 예를 들어 도검 사용 장면이 없는 인물에게 사격/도검 능력을 자동 0점 입력하거나 반대로 높다고 가정하지 않는다.

## 3. 3인 L2 검수 파일럿 — 같은 양식, 다른 사건

| 시험 인물 | 기존 연결 | 주된 복잡성 | 아직 하지 않은 일 |
|---|---|---|---|
| 아킬라 `char-033` | `pilot-A` / **A01~A04** | 실시간 탄약·사거리 판단의 사용자 원작 관찰, 구스타프 심리적 교란 **의도** vs 효과, 제3자 개입, 접근·재이격 | 아킬라 구스타프전 `A01~A04`를 콘·헤론·오울 **별도 교전**과 섞지 않기. 수치/상대 원문 매핑 및 Phase 미검수 |
| 리천 `char-087` | `pilot-L` / **L01~L04** | 표영·라텔·크리사 공격의 **동시/순차** 여부, 부상 전후 상태, 총기 기만과 관절 공격의 인과 | 팬 자료에 적힌 2부 27~30화를 실제 교전 장면이 검증된 것으로 취급하지 않기 |
| 류지학 `char-071` | `pilot-R` / **R01~R04** | 최달천의 피로와 자신의 지속전 차이, **왼쪽 상지 부상** 발생 시점, 시간 압박과 위험 감수 | 부상=방어 감점/빠른 결착=전술 만점 둘 다 보류. 1부 99~100화 원문 미대조 |

**아킬라 L3 실험**은 [국내 커뮤니티·사용자 관찰 비교 초안](https://github.com/pchjesus/castle-combat-analysis/blob/research/v2.7-community-evidence-crosscheck/docs/research/V2_8_AQUILA_DOMESTIC_TACTICAL_REVIEW_DRAFT.md)을 참조할 뿐, 아직 해당 Draft PR을 main에 병합하지 않는다. 국내 한국어 원작 기반 분석·동시대 리뷰를 해외 번역 토론보다 먼저 탐색하되 **원작 직접 대조 여부는 별도 유지**한다.

**3인에서 공통으로 얻을 출력**은 누가 몇 점인지가 아니라 `해당 능력치가 어디서 관찰됐는가? / 같은 관찰이 다른 축과 중복되는가? / 반대 설명이 가능한가? / 사용자 원작 검수가 무엇을 해결하는가?`의 체크 기록이다. 양식이 실제 3인에서 유효해야 L2 전 인물 적용을 승인할 수 있다.

## 4. 자료량에 따른 부당한 점수 차이를 막는 공정성 규칙

| 함정 | 금지 규칙 | 점검 가능한 테스트 |
|---|---|---|
| 아킬라 연구가 길어서 자동 고평가 | 연구 문장 수, Evidence **후보 수**, 커뮤니티 글/좋아요/인용 횟수를 점수·가중치로 사용 금지 | 평가 결과 필드 `null`, 후보 추가가 기존 등급을 바꾸지 않음 |
| 강민성 관련 실전 자료가 적어서 저평가 | '없음'을 0·최저점·E3 자동 확정으로 치환 금지 | 후보 레지스트리 109명 모두 **전투력 점수 없음** |
| 같은 장면이 위키·갤러리에 반복됨 | 같은 사건/글/동일 작성자의 반복을 독립 원작 근거로 증가 금지 | source cluster·원래 Evidence ID로 중복 확인 |
| 유명인만 L3까지 조사 | L3 승격 기준은 **사건의 해석 복잡성**, 원작 장면 충돌·과거/현재 조건이지 인기/서열 아님 | L2 없이 장면·반론 확인 불가능하면 L3 '완료' 표시 금지 |
| 한 명의 최강 시기만 합성 | 원작 시점·무장·부상·임무 목표가 동시에 성립하는지 확인 | Evaluation은 Character 1명 아래 조건별 별도 상태 |
| 매치업 점수로 무리한 승률 산출 | 기본 프로필과 1:1 승률을 같은 것으로 취급 금지 | 상대 무장·초기거리·엄폐·목표 동일 조건과 직접 상성 Evidence 없는 경우 승패/승률 보류 |

실제 장면이 풍부해도 신뢰도가 낮을 수 있고, 짧은 직접 장면 하나가 특정 행위의 좋은 근거가 될 수 있다. 근거 충분도 E1/E2/E3는 **반복·독립성·원작 직접성·반론과 보정 가능성**을 종합한 별도 판단이며 자료 수에 따른 자동 등급은 없다.

## 5. 확장 원칙 — 업무를 줄이는 검수 파이프라인

1. **현재:** 109명 L1 *틀*을 저장하고 원작 검증 없이 초기 소속·무장·명성을 확정하지 않는다.
2. **다음:** 3인 L2 동일 템플릿 검토를 통해 기록 필드·축 중복·심리 상태의 분리가 가능한지 시험한다. 사용자 직접 원작 확인 진술은 가치 있는 별도 증거로 보존하되 AI 원문 검증 상태와 합치지 않는다.
3. **다음:** L2로 확대할 인물은 직책·강약이 아니라 **검증 가능한 사건과 전투 조건**의 존재 여부를 기준으로 선정. 새 인물 유입 시 기존 기록 ID와 같은 규약 사용.
4. **필요할 때:** 동시다중전·심리전·시점 평가 등 해석의 복잡성이 있는 경우에만 L3. `char-052/068/051/056/099` 전성기 후보는 아직 모두 `evaluationStates=[]`와 `splitDecision=not-decided`.
5. **승인 후:** 실제 원작 장면·부/회차 검수와 모델·가중치 승인 후 평가/계산으로 승격. 공개 사이트의 종합점수·매치업/승률은 이후 단계.

**현재 개발 판정:** **구조적 리팩터링 불필요**, 아직 109명에게 표준전투력 점수를 매기는 도구를 만들지 않는다. 사용자 승인 전까지 새 연구 데이터는 별도 브랜치의 Draft PR로만 보존. 웹앱의 109명 탐색/PC·모바일/접이식 사이드바는 그대로 유지.
