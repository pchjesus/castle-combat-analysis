## 변경 범위

- 추가 21건은 사용자 직접 제공 또는 2차 자료 후보에 대한 사용자 선택. **원작 직접 검증 0건**, 정식 공식 인용문으로 확정하지 않음.

## 정확한 표기와 제외 정책
- 실제 대사 원문은 `data/character-quotes.v3.4.DRAFT.json`의 `exactText`를 단일 기준으로 한다. 비속어(`씨X`, `X바` 등), 말투와 줄임표를 자동 교정하지 않는다.
- **남일호**는 직접 발화가 아니라 **노트에 적어 전달한 필담**이라고 사용자가 설명했다. `deliveryMode: written-note`로 별도 기록.
- **신원일**은 사용자 정정에 따라 앞부분 `어이구.. 수민아, 수민아...`를 포함.
- **권수찬**은 `-`로 끝나는 원문을 보존하며 해당 인물만 종료부호 검사의 명시적 예외.
- **송익천** 대사는 빈 상태로 유지. **몽키**도 계속 미등록.

## 검증
- 정적: 신규 21건 정확한 원문, 이전 86건 보존, ID·인물 중복 없음, 107건 전원 원작 미대조·전투력 미연동.
- 브라우저: PC·모바일 대표 명대사 카드 21건 및 기존 인물 검수. 사이드바 스크롤 등 회귀검사 유지.
- 배포: GitHub Actions의 verify/browser-regression/deploy 결과와 실제 Pages HTTPS를 별도로 확인해야 함. 이 문서는 통과 사실을 미리 선언하지 않음.
