## 선정 절차

1. 사용자에게 **상징성·캐릭터성·장면의 파괴력**을 기준으로 인물별 1차 후보를 선택하게 한다.
2. 사용자가 접근 가능한 원작 회차에서 실제 **한국어 원문, 화자, 청자, 부/회차, 장면 배경**을 검수한다. 사용자의 확인을 `user-checked`로 기록하되 **AI 원작 직접 대조 완료로 전환하지 않는다**.
3. 서사적 명대사와 작품 내 상대 평가용 Statement, 그리고 인물이 말하지 않은 연출 문구를 구별한다. 유료 컷 이미지/다량 대사 복제를 요구하거나 자동 게시하지 않는다.
4. 짧은 문구에 대해서도 적절한 출처 명기·공표 목적·권리 검토를 별도 진행한다. 팬 프로젝트라서 법적 허용이 자동 보장되지는 않는다.
5. **선정·검수·권리 검토·공개 승인**이 끝난 항목만 이후 인물 도감에 표시한다. 자료가 없는 인물의 표시 자리를 대사로 채워 넣지 않는다.
