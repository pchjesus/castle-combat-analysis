# 《캐슬》 v5.0 — 3개 조직·토니 진 대표 명대사 및 모바일 사이드바

## 승인된 변경
- 야마구치구미: 기존 **사사키 신겐** 명대사 `CQ-009` 유지, **하야부사** `CQ-081`, **토이시** `CQ-082`, **고로** `CQ-083` 신규.
- 동천방: **모자준** `CQ-084`, **천쿤** `CQ-085`, **우강** `CQ-086` 신규.
- 반야마구치연합: **히데** `CQ-087`, **쿄지** `CQ-088`, **후지타** `CQ-089` 신규.
- 홍콩 거두 세력: **토니 진** `CQ-090` 신규. 토니 진은 동천방 소속이 아니라 사용자가 정의한 **홍콩 거두 세력 초기 분류**의 `char-098` 유지.
- 등록 인물 76명 → **86명**. 이스크라, 백의, 화진, 캐슬 홀딩스, DS씨큐리티, 모리, 호텔캐슬 등의 이전 명대사는 아래 문장부호 3건 외에는 변경하지 않음.
- 신규 10명은 사용자 제공 또는 직전 조사안 승인에 근거하는 **`user-transcribed-secondary`** 레코드로 저장. 원작의 회차·컷을 직접 검증하지 않았으며, 공식 원문 확정·점수 산정에 사용하지 않음.

## 기존 76건 전체 마지막 문장부호 검사
문장 말미가 종결부호 없이 끝나는 **3건만** 변경.
| ID | 인물 | 이전 끝부분 | 수정 |
|---|---|---|---|
| CQ-011 | 최민욱 | 나의 성에도 겨울이 오겠습니까 | 나의 성에도 겨울이 오겠습니까? |
| CQ-024 | 샤모 | 그게 너무 꼴 받아서 눈이 안 감겨 | 그게 너무 꼴 받아서 눈이 안 감겨. |
| CQ-034 | 스내퍼 | 뭐긴 뭐야, '재앙' 이지 | 뭐긴 뭐야, '재앙' 이지. |

의문문에는 `?`, 평서문에는 `.`을 사용. 발언 내용·띄어쓰기·대사 원작 검수 상태 자체는 바꾸지 않음. 기존 최민욱 대표 명대사 교체 이력의 현재 표기도 새 구두점에 일치시키고, `punctuationNormalization`에 전후 문구 추적 기록. 신규 10건까지 **86건 모두** 끝 문장부호 자동 검사.

## 모바일 탐색 UX 버그
원인: `index.html`의 `#mobile-menu` 클릭 핸들러가 사이드바를 렌더링한 직후 `#character-search.focus()`를 호출해 모바일에서 가상 키보드가 즉시 열릴 수 있었음.

수정: 사이드바 열기/닫기 버튼의 포커스 유지로 변경, 검색창에는 자동 포커스를 주지 않음. 사용자가 검색창을 직접 탭하면 정상 입력할 수 있고, PC 접힌 사이드바의 검색 버튼 클릭 시 기존처럼 검색창으로 포커스 이동. Escape 및 닫기 동작도 유지.

## 변경 범위·검증
- 파일: `data/character-quotes.v3.4.DRAFT.json`, `index.html`, 명대사·브라우저·공개 배포 검사.
- 인물 로스터 **109명**, 초기 조직 **17개**, 시점·Evidence·평가모델·계산·호칭 데이터 **무변경**.
- 검사 조건: 신규 10인 동일 ID·원문, 기존 신겐 문구 유지, 문장부호 3건·전체 86건 종결, PC/모바일 카드, 모바일 사이드바 비자동 입력 초점/수동 검색, 배포 HTTPS 데이터 86건.
- 원작 유료 컷의 무단 사용 없음. 원작 직접 대조는 최종 사용자 검수 대기.
- GitHub Actions 실제 성공 여부와 Pages 배포 결과는 별도로 확인.

## 출처
사용자가 이 대화에서 직접 고르거나 제공한 문구 및 직전 대화의 **명대사 2차 자료 연구안**을 활용한 후보 선정. 기존 인물 로스터·인용문은 프로젝트 GitHub의 사용자 선정 데이터. 별도 외부 원작 직접 검수 자료는 이번 변경에서 사용하지 않았으므로 원작 출처 검증을 완료한 것으로 표기하지 않음.
