# 《캐슬》 인물 명대사 — 백의 추가 5명 (2026-10-25)

사용자 요청에 따라 이슬(`char-008`), 박정배(`char-010`), 정선오(`char-011`), 정승영(`char-012`), 서정치(`char-013`)의 제출 문구를 대표 명대사로 채택했다.

- 기존 36건을 변경 없이 보존하고 `CQ-041`~`CQ-045` 5건 추가: **총 41명**.
- 초기 이스크라 19명 전원과 아킬라 대표 명대사 1순위 유지.
- 상단 캐릭터 카드 명대사 위치/접이식 추가 명대사 렌더러 등 v3.9 정상 기능을 변경하지 않음. 데이터 로더는 이미 `>=36`과 고유 Quote ID로 확장을 지원.
- 사용자가 입력한 원문 표기를 보존. 원작 회차 직접 대조가 수행되지 않았으므로 `user-transcribed-secondary` 및 '원작 대조 대기' 유지. 전투력 점수, Evidence, Statement, 계산 모델 무변경.
- 정적검사, 데스크톱/모바일 인물 카드 브라우저 검사, 실제 Pages JSON 41건 확인을 CI로 진행. 결과는 CI 완료에 따라 확인.
- 공개 GitHub 저장소에 인용문을 저장하는 것이 작품 권리자의 인용 허가를 의미하지 않으므로 법적 검토는 별도 단계로 둠.
