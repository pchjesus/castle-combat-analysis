## 1. 이번 단계에서 새로 확인된 자료 한계와 단서

- [O1, O2]는 **네이버웹툰 공식 작품·회차 목록**이며 실제 유료 컷·대사·반응시간의 확인 수단이 아니다.
- [S1]의 2차 행적 설명에서는 리천과 표영·라텔의 전투 **2부 27화에도 등장**한다고 서술하고, **29화에 라텔의 재교전·크리사 개입**을 서술한다. 기존 데이터의 28~29화는 간접 회차 후보였다. **27~29화 범위를 확인 대상에 넣어야 하지만 27화와 29화의 교전 내용은 아직 원작 미대조**이므로 기존 Battle의 정식 회차를 고치지 않는다.
- [S2]는 강민성과 백도찬의 충돌을 두 번의 시점으로 구분한다. 서로 다른 교전 결과를 **강민성의 쇠퇴**로 해석하는 데는 백도찬의 변화/훈련, 첫 교전과 둘째 교전의 다수전·장비·부상·목적이 대안 설명이 된다.
- [S3]은 젊은 최민욱의 대치와 '전성기'라는 별도 개념을 서술한다. **젊은 시절 = 최전성기**로 묶지 않는다.
- [S2]에는 작가 Q&A 일부가 내려갔다는 2차 설명이 있다. **원래 공식 글·공개 프로필의 고유 URL을 직접 확보하지 못했고**, 팬 자료의 재인용으로 공식 원문 검증 상태를 올리지 않는다.

위 단서는 모두 **원본 컷을 확인하기 위한 탐색 정보**이고 원작 Fact에 포함하지 않는다.

## 2. 가장 먼저 원작에서 판별할 4가지 사건

| Evidence | 지지하려는 해석 | 별도로 성립 가능한 해석 | 실제 원작 컷에서 필요한 결정 정보 |
|---|---|---|---|
| **A02** | 경호원 출현을 보고 아킬라가 고속 표적 전환 | 사전에 경호원을 감시·예상한 준비된 사격 | 위협 등장→아킬라 인지→총구 이동→발사→경호원 결과의 **명시적 선후**. 사전 조준이면 반응능력으로 연결하지 않음 |
| **A03** | 재장전·무장 전환하면서 거리와 흐름을 통제 | 엄폐·상대의 선택으로 생긴 여유에 숙련된 루틴 실행 | 총·양손·잔탄·거리·상대 접근을 **컷 순서**로 구분. 돌발 변수가 없으면 '상황 대응'으로 자동 승격하지 않음 |
| **L04** | 리천이 교전 상대 전환과 무장 대응을 주도 | 표영의 시간 확보·라텔의 기존 손상·크리사 후발 개입이 결과를 결정 | **27~29화 원작 대조 대상(2차 회차 후보)**: 표영/라텔/크리사 진입과 이탈을 타임라인으로 만들어 실제 겹친 공격만 동시전이라 부름 |
| **R04** | 부상을 감수하면서 시간 압박 아래 승리 목표를 유지 | 부상의 발생 시점이 잘못 연결됐거나 위험 감수 동기 자체가 해석 | 왼쪽 팔/어깨의 **첫 손상 컷**, 직전·직후 수행, 제시된 임무 시간·목적. 시간 압박을 원작이 직접 말하지 않으면 심리/전술 점수로 단정 금지 |

전체 12 Evidence의 **핵심 주장, 대안 설명, 필요한 관찰, 금지 추론, 원본 Source ID**는 기계검사가 가능한 위 JSON에 입력했다. 후보 상태는 모두 `not-checked`이며 기존 12개의 원본 데이터와 질문 대장은 변경하지 않는다.

## 3. 근거를 축에 연결할 때의 새 판정 규칙

### 같은 행동의 복수 해석이 가능한 경우

1. **Fact 후보:** 눈으로 보이는 행동, 무장과 순서, 실제 발생한 상대의 피해를 분리. 도달 가능한 출처는 현재 모두 간접 근거이므로 여기서는 '후보'다.
2. **Context 후보:** 사전 준비, 탄약·무장, 시작 거리, 엄폐, 제3자, 목적, 부상/피로, 정보 등 **능력치가 아닌 교전 조건**을 먼저 기록한다.
3. **Interpretation 후보:** 적어도 하나의 **대안 인과**를 기록한다. 예: '반응이 빨랐다' vs '사전 정보를 이용해 예상했다'.
4. **Evaluation 보류:** 위 두 해석 중 어떤 것이 실제 컷에 더 들어맞는지 판별 불가하면 primary/secondary조차 실험값으로 남기고 점수는 비운다. 근거 충분도 E3를 이유로 0점/감점하지 않는다.
5. **중복 검출:** `같은 공격 동작 → 같은 피해`를 사격 전문성·반응·공격 실효성에 세 번 별도 성과처럼 계상하지 않는다. 명시적으로 구분된 인지/공격/위협통제 단계가 확인될 때만 각 축의 별도 Evidence 연결을 검토한다.

**중요한 미세 구분:** `primary`는 문장의 '진실성'이나 수치 가산 배율을 뜻하지 않는다. 한 Evidence가 사격 전문성과 기동에 모두 관련되어도 그 자체로 산술 이득이 생기지 않는다.

### 8+1에 대한 반증 가능한 경계 테스트

| 축 경계 | 이 축을 입증하려면 | 반증 또는 유보 상황 |
|---|---|---|
| **기동 vs 반응** | 기동: 시작/끝 위치 및 거리 변화. 반응: 의외의 자극 뒤 **인지→대응** 근거 | 사전 조준/예상된 전법이면 '빠른 반응' 추론 미확정 |
| **방어 vs 지속전** | 방어: 실제 공격 차단/회피 결과. 지속전: 시간이 흐른 뒤 **본인 기능 유지** | 부상 1회, 상대 피로만으로는 자기 지속전 부족/우수 입증 불가 |
| **전술·판단 vs 상황 대응** | 전술: 준비된 의도/선택. 상황 대응: 원계획이 흔들린 뒤 새 전법으로 변경 | 다채로운 계획 동작만 있으면 적응성 입증 유보 |
| **전문기술 vs 공격 성과** | 전문기술: 조작·정확한 동작. 공격 성과: 상대의 실제 피해/전투 중단 | 방탄/거리/엄폐로 피해가 없더라도 조작 기술을 자동 낮춤 금지 |
| **부동심 vs 심리전 vs 상태 감정** | 자기 안정/상대 판단 변화/순간 분노 등의 **관찰 대상을 분리** | 무표정=부동심 최대, 분노=수행 실패, 위협적 대사=심리전 성공으로 단정 금지 |

전문역량 미사용과 자료 부족은 모두 **점수가 없음**을 의미하며, 적용 불가능한 전문영역과도 구별한다.

## 4. 과거/전성기 상태 분리 — 시간축과 일시 상태를 이원화하지 않는다

`Character`는 1개, 평가 상태는 여러 개 가능하되, 제안하는 **시점 상태 축**과 **일시 조건 축**을 구별한다.

- **시점/성장 구간:** 젊은 성장기 / 전성기 / 후기, 은퇴 전 / 복귀 후 등 원작 자료가 실제 지원하는 시점에 한함
- **일시 조건:** 당일 부상, 피로, 심리적 압박, 무장 부족 등의 매치업 환경. **후기의 영구 능력 상태와 임의 합성하지 않는다.**

| 인물 | 분리 후보 | 이원화 결정을 미룰 이유 |
|---|---|---|
| **오도화** | 과거 활동기 / 후기 | 원작 속 '전성기' 직접 평가인지 작중 화자의 전언인지 불명. 후기 총상·다수전 결과와 노쇠를 분리 |
| **현석** | 은퇴 전 / 복귀 후 | 공식 프로필 **원본** 및 은퇴 전 직접 전투 표본이 없을 가능성. 11강 지위만으로 비교 점수 결론 불가 |
| **임무열** | 과거 조직 활동기 / 후기 | 과거 명성·조직 내 평가를 기량으로 그대로 환산할 수 없음 |
| **최민욱** | **젊은 성장기 / 전성기 후보 / 후기** | 시기 3개가 서로 다르다면 강제 2개 점수는 정보 손실·시점 혼동 |
| **강민성** | 초기 활동기 / 최후 교전기 | 2차 자료의 두 충돌이 실제 원작에서 다른 시점인지 확인 필요, **사망 후 현재 상태 생성 금지** |

**원작 검수 게이트:** 최소 두 시점의 작품/공식 근거 각각 확보 → 전투 환경/대상/인과 비교 → 실전 근거 충분도 독립 검토 → 사용자 승인. 그전까지 `evaluationStates=[]`, `splitDecision=undecided`.

## 5. Statement 7건·명대사 관계

`ST01~ST07`에 네 차원의 불확실성을 별도로 기록했다: **발언 존재/원문, 화자 당시 정보, 발언의 진위, Outcome과의 인과**. 발언의 존재를 증명해도 주장의 진실성이 증명되는 건 아니다. ST03의 아킬라 우세 평을 1:1 승률로 직접 바꾸지 않는다.

**명대사 레지스트리 = 0건.** 유명한 대사라 하더라도 원본 회차/컷·발언자·정식 번역을 직접 검수하고 공개 인용 권리까지 확인하기 전에는 등록/노출하지 않는다.
