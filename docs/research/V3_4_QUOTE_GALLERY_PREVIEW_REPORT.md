## 3. 화면 연동과 호환성

기존 `index.html` 도감 화면의 `quotationPanel()`이 **신규 사용자 큐레이션 미리보기 JSON을 선택적으로 읽도록** 변경했다. 9건은 해당 인물 도감에서 텍스트로 표시하며, 큰 인용문과 확인 상태를 구분한다. 아킬라 1순위는 자료 메타데이터로 보존한다. XSS 방지용 기존 `h()` escape를 그대로 사용한다.

- *신규 소스 파일이 없거나 검증 실패 시*: 기존 `data/quotation-review.v0.1.json` 기반 정식 검증 명대사 로직으로 되돌아간다.
- *출처 표시*: 원작 직접 검증으로 오인하지 않도록 `USER CURATED`와 `원작 대조 대기` 표시.
- *전투 점수*: 명대사가 증거로 자동 변환되거나 부동심 점수에 가산되지 않음. 일반 전투 UI, 사이드바, 순위, 검색, 데이터 저장은 수정하지 않음.
- *공개 범위*: 브랜치에서 코드와 데이터 열람 가능. **main merge·GitHub Pages 배포는 이번에 실행하지 않음**.
- *이미지*: 새 이미지/컷 사용, 외부 hotlink, 파일 재배포 0건.
