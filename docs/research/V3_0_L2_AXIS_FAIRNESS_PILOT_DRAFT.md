## 1. 핵심 판단

동일 L2 스키마를 3인에게 적용하는 **기록 구조의 시험은 가능**하다. 하지만 **8개 공통축+대표 전문 1축이 실제로 서로 구분 가능한지에 대한 경험적 타당성은 아직 충분하지 않다**. 특히 전술·판단/상황 대응, 전문기술/공격 결과, 자기 부동심/상대 심리전은 **관찰 단위를 다르게 정의**해야 한다. 12개 Evidence는 각각 전투 사실로 확인한 12개의 독립 장면이 아니라 **기존 2차 서술의 후보 12개**다.

동일 L2 **입력 양식**은 공평하게 적용하되, 축별 **점수 기입 의무**를 부과하지 않는다. `null`은 0점이 아니다. 분석 깊이 L2는 근거 충분도 E1/E2/E3나 강함의 티어가 아니다.

새 연구 데이터: [L2 공통축 귀속 시험(JSON)](../../data/research/l2-axis-attribution.v3.0.DRAFT.json). 이전 [109명 L1 / 3인 L2 후보 스키마](../../data/research/analysis-depth-coverage.v2.9.DRAFT.json)·로스터·Evidence·Review Queue는 편집하지 않았다. **기존 Evidence/Statement ID만 연결**하며 이 자료는 새로운 canon source가 아니다.

### 아킬라의 국내 전술 연구를 어디에 놓을 것인가

v2.8의 사용자 원작 열람 진술은 (a) 구스타프에 대한 상대 심리적 우위 약화 의도, (b) **별도 사건** 콘·헤론·오울에서 `0발`/`사거리 미달`/`8/10발` 표기 관찰을 구분한다. 국내 독자 D01/D03/D04는 **빠른 결착**, **접근의 실익에 대한 반론**, **원거리 교착을 피하려는 심리적 압박** 등 서로 다른 설명이다. **AI의 원작 컷 직접 대조는 하지 않았으며**, 전술 의도나 심리 영향의 진위 및 AK-KHO 수치-대상 대응은 현재 확정할 수 없다.

이 정보는 `pilot-A` A01~A04의 명중·회피 증거에 자동으로 더하지 않는다. 별도 사용자 진술 메모로 보존하고 **독립 원작 검증·교전 시점·심리 효과** 확인 뒤에만 Evidence 연결을 검토한다. ST03(아킬라/블랙맘바 정면 총격 조건부 비교) 및 ST04(작전 위험 예고)는 원문 미대조 **Statement 후보**다. 인물 능력치 검증을 대신하지 않는다.

## 3. 8개 공통축의 구분 시험

| 경계 / 범위 | L2 관찰 규칙 | 이번 12건에서 얻은 판단 |
|---|---|---|
| 신체 역량 vs 근접 기술 | 실제 힘·폭발력의 독립 출력과 타격 기술을 분리 | A04/L01의 결과만으로 신체축 확정 불가 |
| 기동 vs 반응 | 거리/위치 변화와 **예상 밖 위협의 인지→대응** 구분 | R01 기동 후보, A02 반응 후보. 컷간 시간 없으면 속도 계량 불가 |
| 방어 vs 지속전 | 피격 방지와 **시간·피로 경과에 따른 본인 수행 유지** 별개 | R04는 부상 상태 우선, 둘 다 평가 보류 |
| 전술·판단 vs 상황 대응 | 사전에 이용 가능한 정보·전략 선택 vs 예상 밖 변수 발생 뒤 **실제 계획 변경** | A03/L03/L04/R02에서 중복 위험 큼. 사전 계획과 후발 변수 미확정 |
| 부동심 vs 심리전 vs 상태 감정 | 자기 판단 안정·상대 판단 개입 의도·상대 행동 변화·일시 감정을 서로 별도 관찰 | 12개 Evidence에서 부동심 확정 직접 관찰 **없음**. 심리전은 **비채점 해석 렌즈**, 공통 9번째 축 아님 |
| 전문 수행 vs 공격 실효성 | 조작·정확성·전환과 명중·기능 제압·전투 종료의 결과 분리 | A01/A02/L01/L02/R03의 결과 설명을 전문 1축과 중복 보상하지 않음 |
| 공통 8축 + 전문 1축 | 전투 문맥별 전문 분야 후보들을 기록한 뒤 대표 전문 분야 *선정 결정* 별도 보류 | 아킬라 사격+근접, 리천 맨손+사격, 류지학 도검으로 **전문 능력이 다종**. 성급한 1분야 대표 선발은 편향 가능 |

이번 자료의 **12개 우선 귀속 가설**은 전문 영역 7, 전술·판단 3, 기동 1, 부상 맥락 1이다. 이는 데이터가 보여 주는 관찰 가능 범위이지 인물별 능력 우열의 분포가 아니다. **신체 역량·반응·방어·지속전·부동심·상황 대응에 대한 독립된 우선 관찰은 이 후보 자료에서 아직 확보되지 않았다.** 능력 부재나 0점을 뜻하지 않는다.

## 4. 근거량·출처 독립성 공정성 감사

1. **균형처럼 보이는 4:4:4의 함정:** 각 인물의 후보 4개는 연구 편집의 산물이며 같은 분량/장면 수/독립성/확실성을 보장하지 않는다. 12개 후보 모두 `secondary-only`, `sceneCanonVerified=false`다.
2. **아킬라의 추가 연구 깊이:** 국내 독자 4건·위키 서술과 사용자 원작 열람 진술이 더 있는 사실은 **전투 실력 점수 상승 근거가 아니라 탐색/검수 범위의 차이**다. 리천/류지학의 미연구 부분을 기량 부족으로 다루지 않는다.
3. **source cluster:** 한 위키 설명을 근거별로 재단하거나 다른 문서에서 다시 인용한 것은 원작 독립 확인 건수를 늘리지 않는다. R04 출처가 2개인 것 또한 독립 원작 검수 2건으로 단정 불가. 동일 사건/원문/작성자의 복제 가능성을 별도 검수한다.
4. **반사실적 공정성 검사:** 동일 출처 ID를 반복 기재해도 점수/E등급은 `null`/`unassessed`로 유지한다. Evidence 후보 증가와 평가 향상을 연결하는 계산 기능은 없다.
5. **부재 처리:** `not-used`, `ability-unknown`, `not-applicable`, `unassessed`, `used-with-observation`는 서로 다르다. **현재 12건의 전문 상태는 모두 `unassessed`**로 두었다. 본 장면에서 사용하지 않은 능력이 곧 그 인물의 낮은 숙련을 뜻하지 않는다.
6. **교전 공정성:** 상대 목적·부상·피로·사거리·엄폐·개입 시점이 상이하므로 후보 성과를 동일 조건 승패로 환산할 수 없다. 어떤 1:1 승률도 산출하지 않는다.

## 7. 109명 확장 판단

**L2 양식의 109명 재사용은 조건부 가능. 8+1 점수 모델의 109명 공정 적용은 아직 통과로 판단할 수 없다.**

- L1 전체 109명은 현재 **인물 ID와 후보 조직만 등록**된 상태. 일반 전투 프로필/주력 무장까지 작성된 것이 아니다.
- L2는 **검수 가능한 독립 사건**이 있고 사실/조건/반론을 구분할 수 있는 인물부터 적용. 기록은 복수 사건/시점 상태 연결을 허용하고 없으면 공란으로 남긴다.
- 다음 파일럿은 총기 사용, 근접, 도검 외에 **회피·부상 후 지속·비전투/교전 부족** 사례를 고르게 선택한다. 유명인·전투력·문서량을 기준으로 선택하지 않는다.
- 각 인물의 **가용 관찰량, 출처 독립성, 직접성, 상충 설명**을 별도 관리한다. 단일 최고 시기의 역량을 다른 시점·무장과 혼합하지 않는다.
- 8축의 관찰 분별성, 전문 다종 프로필의 비교 가능성, 심리 해석의 타당도, E등급 판별 일관성은 **직접 컷 검수와 복수 검토자 교차 분류** 이후 재평가한다.
