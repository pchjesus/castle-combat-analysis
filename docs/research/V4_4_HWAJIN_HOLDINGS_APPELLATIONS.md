# 《캐슬》 화진·캐슬 홀딩스 이명·별칭 추가 v4.4

## 범위
2026-11-01 사용자 요청에 따라 기존 `main`의 캐릭터 상단 카드 호칭 데이터만 확장했다. 사용자 직접 선정한 8명과 기존 19명 이스크라 코드네임 동물 뜻은 원문·평가 상태 그대로 보존했다.

### 신규 화진 3명
- 유우성 (`char-080`): **롱터우** (대표) / 페이룽 / 토룡. 원문 중국어 표기 龍頭, 飛龍, 土龍은 2차 인물 문서 참조.
- 도우첸 (`char-082`): **투견** (대표) / 거지 (다른 이명). '장쉬'는 본명이므로 호칭 배열에 넣지 않음.
- 리천 (`char-087`): **대륙 제일의 살수** (대표) / 김신의 대항마. '캐슬 11강' 같은 평가·등급과 구별.

### 신규 캐슬 홀딩스 4명
- 마학영 (`char-057`): **마운틴** (델타포스 코드명) / 인간 마지노선 / 캐슬의 수문장.
- 마준영 (`char-058`): **봄버** (코드명).
- 정단 (`char-060`): **콜트** (코드명).
- 사인진 (`char-061`): **마귀** (이명).

**추가하지 않음:** 링링(현재 표기와 다른 본명 링샤오 혼동 방지), 앤디청·주천명·은보·양사(사천왕은 집단의 지위), 최민욱(하늘 등 비공식 해석과 호칭 혼동 가능), 이정화, 마크(검증 가능한 독립 호칭 부족). 없는 인물은 비어 있는 UI가 뜨지 않음.

### 데이터·안전성
- `data/character-appellations.v1.0.DRAFT.json`: 기존 27 프로필 → 34 프로필. 대표 이명 기존 8 + 2차 자료 검토 7 = 15명. 초기 이스크라 동물어원 19명 유지.
- 각 신규 항목에 나무위키 개별 인물 문서 링크 및 `originalChecked:false`를 유지. 사용자 직접 검수 확정·원작 근거와 분리.
- `index.html`의 호칭 데이터 로더 길이 검증을 `===27`에서 `>=27`로 개선하고 고유 ID와 캐릭터 이름·값 검증은 유지. 여러 이명은 기존 UI의 대표+보조 방식으로 표시.
- 원작 유료 컷/이미지 복제 없음. 인물 109명, 조직 17개, 기존 대표 명대사 53명, 전투력 미평가 및 근거 독립성 보존.
- 검증: 정적 34인, 브라우저 PC/모바일 8명 기존·7명 신규·19 이스크라 + 무호칭 8명, 실제 Pages HTTPS 데이터/화면 검사.
