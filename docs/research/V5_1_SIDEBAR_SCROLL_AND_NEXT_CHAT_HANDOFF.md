# 《캐슬》 v5.1 — PC·모바일 인물 탐색 스크롤 위치 유지 및 최민욱 구두점 수정

## 요청 및 재현 원인
- PC: 사이드바의 109인 목록 아래쪽에서 인물 선택 후 목록이 맨 위로 초기화.
- 모바일: 사이드바(드로어)에서 인물 선택 → 드로어 자동 닫힘 → 다시 열면 스크롤이 맨 위로 초기화.
- 원인: `render()`가 매번 `root.innerHTML`로 `aside#sidebar` 전체를 새로 생성. 기존 스크롤 `scrollTop`을 잃음.
- 기존 `setCharacter()`의 `window.scrollTo({top:0})`는 본문을 위에서 보기 위한 동작이므로 유지하고 **사이드바 스크롤만 보존**.

## 구현
- `index.html`의 `render()`에서 이전 펼친 `#sidebar.scrollTop`을 캡처해 새로 생성한 펼친 `#sidebar`에 복원.
- 접힌 PC 사이드바는 목록 스크롤을 변경하지 않으며, 다시 펼쳤을 때 종전 위치를 재사용.
- 모바일은 인물을 선택해 드로어가 닫힌 뒤에도 스크롤 상태가 남아, 다시 열면 종전 위치로 돌아감.
- 기존 검색·조직 필터·선택된 인물 표시·탭·Escape·모바일 자동 검색창 포커스 방지 동작 유지.
- 브라우저 회귀검사: PC·모바일 각 지원 뷰포트에서 하단 캐릭터 드미트리(`char-108`)와 바실리(`char-107`)를 차례로 선택하고, 사이드바 스크롤 위치가 ±2px 이내로 유지되는지 비교. 모바일의 드로어 자동 닫힘·다시 열기 확인.
- 실제 웹사이트의 재렌더링과 동시에 발생하는 목록 높이 제한에 따라 브라우저가 클램프하는 일반적인 경우는 허용. 페이지 새로고침이나 새 세션까지 스크롤을 저장하는 기능은 요구하지 않았으므로 구현하지 않음.

## 최민욱 명대사
- `CQ-011` 기존 “나의 성에도 겨울이 오겠습니까?” → **“나의 성에도 겨울이 오겠습니까.”**
- 사용자 직접 정정에 따라 마침표 `.` 사용.
- 해당 명대사 교체 이력의 현재 문구와 이전 문장부호 보정 기록 및 정적·공개·브라우저 검사도 새 표기와 일치시킴.
- 이 정정은 사용자 지정 표기이며, 원작 유료 컷을 AI가 직접 대조했다는 뜻은 아님.
- 총 대표 명대사 **86명**, 인물 **109명**, 조직 **17개**, 호칭 프로필 **37명** 그대로. 전투력 평가·Evidence·모델 불변.

## 새 채팅 인수인계
- 최신 `main`을 먼저 확인하고, 본 문서와 최신 명대사/호칭 데이터 중 필요한 자료만 읽기.
- 명대사 선정 작업은 **86/109명**. 미선정 **23명**:
  - 백의 11명: 송익천, 남일호, 어광득, 도학수, 최혁진, 김성준, 신원일, 장호, 인수, 원용, 남용.
  - 선진무역: 몽키 1명 — 사용자 요청으로 의도적으로 미등록. 우선 재제안하지 말 것.
  - 파천 5명: 강민성, 도지웅, 차일국, 권수찬, 표성.
  - 대국 3명: 위길성, 백강회, 쌍개.
  - 기타 3명: 바실리, 드미트리, 훌리안 카스티요.
- 다음 명대사 작업은 **파천·대국·기타 3집단**부터 2~3개 묶어서 조사·사용자 선정하는 순서를 권장. 백의 잔여 11명도 후속으로 진행. 원문을 확인할 수 없으면 보류하고 없는 회차/대사를 만들지 않기.
- 개인 이명/별명/활동명/일본명은 출처를 구분하고 `originalChecked:false`를 유지. 장면에서 검수하지 않은 2차 자료를 원작 검증 완료로 승격 금지.
- **명대사 선정이 마무리되면 전투력 모델 연구로 복귀**: 아킬라·리천·류지학 3인 MVP 평가 실험, 평가축 8/10 원안과 가중치/대표 전문성 가설 미확정, Canon Fact → Context → Interpretation → Evaluation → Calculation 분리. 근거 충분도 E1/E2/E3 별도 기록. 원피스 저장소 읽기 전용, 공식 전투 점수 확정·배포는 사용자 승인 필요.
- 사용자 선정을 받기 전에 다음 인물의 명대사·점수를 자동 추가하지 않기.
