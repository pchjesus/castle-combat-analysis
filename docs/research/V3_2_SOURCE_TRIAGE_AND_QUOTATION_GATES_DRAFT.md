# 《캐슬》 v3.2 — 실제 접근 가능한 근거 점검과 축 충돌 연구 / 명대사 게이트 (승인 전 DRAFT)

기준: 2026-10-25. 기반 `research/v3.1-axis-observation-validation` @ `83696a3d7daff6aa190affef63643c83d083b267`. 대상: 아킬라·리천·류지학의 v3.1 L2 검수 양식 **유지**, v3.2 자료 탐색 **5개 충돌 사례에 한정**.

**핵심 판정:** 공식 네이버웹툰 작품 목록과 국내 한국어 2차 텍스트 일부의 접근·내용은 확인했지만, **원작 유료 컷 및 정확한 발언은 0건 대조**하였다. 따라서 이번 작업은 실제 원작 장면에 대한 검수 완료, 독립 코더 분류, 축의 경험적 타당도 통과가 **아니다**. 확인할 수 있는 2차 자료가 더 생겨도 AI가 원작을 직접 읽었다고 표시하지 않는다.

## 1. 이번에 실제 확인한 자료 범위

- 공식 `캐슬` 1부 [작품·회차 목록](https://m.comic.naver.com/webtoon/list?titleId=736744)에서는 **총 121개 항목이 표시**되고 이 목록의 초기 페이지에서 7화 이후가 유료로 표시된다. 1부 99~100화의 **전투 장면은 열람하지 않았으며**, 그 회차가 특정 교전의 실제 위치인지도 미검증.
- 공식 `캐슬2: 만인지상` [작품·회차 목록](https://m.comic.naver.com/webtoon/list?titleId=807178)에서는 **총 136개 항목이 표시**, 28·29화의 목록과 유료 표시를 확인했다. 실제로 리천·라텔·표영·크리사가 그 두 회차에서 어떤 순서로 전투했는지는 검증하지 못했다.
- 한국어 2차 편집형 자료 [아킬라](https://d.namu.moe/w/아킬라(캐슬)/전투력), [리천](https://m.namu.moe/w/리천(캐슬)/전투력), [류지학](https://www.namu.moe/w/류지학/전투력)의 **검색 결과에 표시된 텍스트**를 확인했다. 페이지 원문 재열람은 일부 실패했으므로 `search-result-text-reviewed-original-page-recheck-limited`로 기록했다. 이것은 공식 원작 원문 대조가 아니다.
- 국내 독자 글 [캐슬 스토리 진행과 직결되는 라이벌구도 및 부상관리](https://gall.dcinside.com/mgallery/board/view/?id=castlewebtoon&no=107902)(2023-06-11)의 **검색 결과 텍스트**를 확인했다. 류지학의 왼팔/어깨가 최달천전에서 다쳤고 빠른 결착의 대가였다는 해석이 담겨 있다. **부상 발생**과 **의도적으로 위험을 감수한 원인**은 별도 주장이다. 글 첨부 이미지는 확인·복제·재배포하지 않았다.

각각의 **출처 유형**(공식 회차 인덱스, 국내 편집형 요약, 국내 독자 해석)과 **접근 상태**(공식 목록 열람, 검색결과 텍스트 확인, 원작 장면 미확인)를 별도 데이터로 기록했다. 이 출처들은 독립된 **원작 검증 건수**에 포함하지 않는다.

자료: [5건 targeted source triage](../../data/research/targeted-source-triage.v3.2.DRAFT.json).

**중요:** 출처가 여러 개라고 증거가 몇 배 강해진다는 의미가 아니다. 위키를 다른 글이 반복 인용했는지, 독자의 원작 관찰이 독립적인지, 한 문서에서 동일 사건의 유도·공격·승패를 중복 셌는지를 추후 확인한다. 원작 확인 없이 P1/P2 등 기존 검수 우선순위도 변경하지 않는다.

v3.1의 원작 검수 양식 12건·5개 축 충돌 판별 기준과 아킬라의 `AK-KHO` 별도 사용자 원작 관찰 기록은 **그대로 둔다**. v3.2에서 새로운 확정 Battle·Phase·인물·Statement를 만들어내지 않는다.

## 3. 실제 모델 타당도 시험을 시작할 때 필요한 입력

1. **검수 가능한 원작 장면**: 사용자가 열람한 원작의 부/회차·개인용 컷 위치, 전투 순서·당사자 정보·목적·엄폐·탄약·부상 등 최소 맥락. 유료 컷 공개 업로드를 요구하거나 접근제한을 우회하지 않는다.
2. **사실과 해석 분리**: 유도/심리전/상황 대응을 판별하려면 실제 **의도 → 정보·행동 → 상대 인식 → 선택 변화 → 결과**의 연결을 분리. 상대의 명중/부상/공포 자체는 본인 능력치의 중복 가산 근거 아님.
3. **독립 분류**: 동일한 원작 관찰 메모를 두 검토자가 판독한 후, 원작 확인된 행동과 가설을 분리해서 축에 귀속. 실제로 진행되기 전 일치율/카파를 산출하지 않는다.
4. **사용자 승인**: 원작 직접 대조 상태와 해석 합의가 확보되더라도 점수·가중치·E1/E2/E3·승률은 별도 승인 후에만 정한다.

**현 v3.2에서 직접 검증된 원작 장면 0건 / 확정 점수 0건 / 독립 코더 평가 0건**. 따라서 경험적 구분 타당도는 미검증, 작업상 검수 질문의 우선순위만 선명해졌다.

## 4. 명대사 추가 — 지금부터 연구, 공개는 나중에

기존 `data/quotation-review.v0.1.json`은 `quotationCandidates=[]`. 사용자가 원한 명대사 기능은 **전투력 점수에 영향을 주는 Statement와 별개인 인물 도감 서사 요소**다. 발언이 있었다는 사실과 발언의 진실성도 별개다.

- **v3.2 지금:** [명대사 입력 게이트](../../data/research/quotation-intake-policy.v3.2.DRAFT.json)만 작성. *원작 대사 내용은 새로 만들지 않고, 기존 빈 목록도 유지.* 후보 접수·정확한 원문 확인·대표성 승인·권리 검토·공개 승인의 단계 분리.
- **v3.3 제안:** 김신·아킬라·리천·류지학 등 희망 인물부터 **검증 가능한 후보**를 수집. 실제 원작 한국어 표현, 화자·청자·부/회차·시점, 인상 깊은 이유를 기록. 회차를 2차 자료에서만 알게 된 경우 원작 검수 전까지 후보로 둔다.
- **v3.4 제안:** 검수 완료·사용자 선정·인용 적법성 검토·공개 승인이 모두 충족된 것만 도감에 **짧고 정확한 출처 표시와 함께** 노출하는 제한된 UI를 검토. 자료가 미확인인 인물은 강제 인용문 없이 표시.

**명대사 선정 ≠ Statement 진위 확인 ≠ 전투력 평가 증거.** 텍스트 몇 글자 이하면 무조건 적법하다는 식의 임의 기준은 두지 않는다. 비영리라는 이유만으로 유료 원작 컷·장문 대사를 공개 게시하지 않으며, 적절한 인용 판단이 어려우면 줄거리 요약과 공식 회차 링크로 대체한다.

## 5. 변경 안전성과 다음 단계

- 새 파일은 **연구 JSON 2종 + 연구 보고서 + 정적 테스트 + 별도 브랜치 CI**만 포함. `main`, `index.html`, 기존 v2.1 Evidence/Statement·v2.2 검수 대장·v2.9/v3.0/v3.1 기록·`data/quotation-review.v0.1.json`은 그대로.
- **검증:** MVP(109명/17조직), 기존 Evidence·Review 참조, v2.9 분석 깊이, v3.0 L2 공정성, v3.1 미검수 상태, v3.2 원작/출처/인용 게이트를 CI에서 정적 검사. **실행 결과 확인 전 PASS 주장 금지**.
- 새 원작 검수가 불가능하다면 연구 결과를 정식 평가로 승격시키지 않고, 실제 컷을 직접 열람한 사용자의 검수 메모가 입력되기 전까지 `originalSceneVerified=false` 유지.
- **109명 확대**는 대표 교전이 부족하거나 방어/지속전 관찰이 많은 사례에서 축 귀속 규칙을 검증한 뒤 별도 추진. 이번에 강제 확대하지 않는다.
